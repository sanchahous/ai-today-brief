## 2. Методологія вимірювання та правила порівняння

Для забезпечення статистичної чистоти порівняння застосовуються такі правила:
1. **Канонічна GA4-property**: `540206735` (акаунт `396774992`, ідентифікатор `G-5R89X6Q5D4`). Інші акаунти вимкнені або переміщені в кошик. (source: [redesign baseline](2026-09-29-redesign-baseline.md) §1)
2. **Виключення бот-трафіку**: трафік з ASN 132203 (Tencent Cloud, Сінгапур), заблокований на рівні Vercel Firewall 2026-10-02, виключається з обох періодів для порівняння. Чистий базовий період — 2026-09-01 … 2026-09-21. (source: [singapore bot traffic](2026-10-02-singapore-bot-traffic.md))
3. **Виключення власних headless-перевірок**: внутрішній трафік агентів та розробника з Івано-Франківська відфільтровується через `navigator.webdriver === true`. (source: [singapore bot traffic](2026-10-02-singapore-bot-traffic.md) §Код)
4. **Зіставлення днів тижня**: кожні 7 днів після релізу порівнюються з відповідними днями тижня базового періоду (понеділок до понеділка тощо).
5. **Розділення джерел трафіку**: метрики розглядаються окремо для Organic Search, Direct, Organic Social та AI Assistants.

### 4.2 Покриття та індексація у Google Search Console
- **Джерело даних**: Google Search Console (ресурс `aitodaybrief.com`).
- **Цільові показники**:
  - Скорочення пулу «Виявлено — не проіндексовано» (baseline: 232 сторінки).
  - Успішна індексація оновлених хабів новин та категорій.
  - Сторінка пошуку `/[lang]/news/search` коректно тримає `noindex,follow` з канонічним посиланням на `/news`.
- **Поточний стан**: очікується оновлення звітів GSC (затримка 48–72 години).

### 4.3 Core Web Vitals (CWV) у реальних умовах
- **Джерело даних**: Chrome User Experience Report (CrUX) та Vercel Speed Insights.
- **Цільові бюджети проекту** ([after-hours-redesign](../product/after-hours-redesign.md) §Критерії):
  - LCP ≤ 2,0 с (Largest Contentful Paint).
  - INP ≤ 200 мс (Interaction to Next Paint).
  - CLS ≤ 0,05 (Cumulative Layout Shift).
- **Поточний стан**: польові дані CrUX накопичуються протягом 28 днів; лабораторний аудит на прев'ю (AH-7.2) підтвердив виконання бюджетів CLS та INP. (source: [after-hours-cwv-preview](../audits/2026-10-05-after-hours-cwv-preview.md))
