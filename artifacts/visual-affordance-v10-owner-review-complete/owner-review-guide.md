# V10 Owner Review Guide

This package contains the persisted V10 v3 owner-review materials that were actually produced by the workflow.

For each V10 card, choose one decision: `approve`, `local repair`, `major rework`, or `reject`.

Useful reason tags: `weak_context`, `broken_arrow`, `anatomy_error`, `weak_visual_thesis`, `good_concept_bad_execution`, `domain_context_success`.

Important: automated publication is disabled; every production decision requires owner approval.
