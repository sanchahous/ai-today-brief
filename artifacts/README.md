# artifacts/ — готові деліверабли

Усе, що віддається людині або команді як **закінчений результат**: дашборди, one-pager-и,
згенеровані сайти, PDF, презентації, бренд-ассети, скріншоти, експорти.

## Правило

Кожен артефакт — **безпечно видалити й перегенерувати**. Якщо щось не можна відтворити з
`raw/` + `wiki/` + коду — це не артефакт, а або сире джерело (`raw/`), або знання (`wiki/`).

## Структура

Один артефакт — одна папка `artifacts/{slug}/`:

```
artifacts/
  brand-kit/                 бренд-ассети (SVG-банери, аватар, шаблони карток)
  weekly-pdf-samples/        згенеровані приклади weekly PDF
  {slug}/
    index.html | *.pdf | *.svg | *.png
    README.md                що це, з чого згенеровано, коли, як перегенерувати
  _local/                    git-ignored: bulk-скріншоти, відео, важкі бінарники
```

`README.md` усередині артефакту — обов'язковий, якщо артефакт не самоочевидний. Мінімум:
що це, з якої wiki-сторінки/джерела зроблено, дата, команда для перегенерації.

## Що НЕ кладемо сюди

- Markdown-знання й аналіз → `wiki/`.
- Сирі дані → `raw/`.
- Те, що рендерить сам сайт (`public/`, `src/app/`) → лишається в коді.
