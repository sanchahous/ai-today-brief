## Було → стало

Базовий прогін (`qa/qa-baseline.json`) зроблено тим самим харнесом на прототипі до змін: 26 маршрутів × desktop/mobile × 2 теми × 2 мови = 208 сторінок. Фінальний прогін ширший (560 сторінок, додано 1024/768/360).

| Метрика | До | Після |
|---|---|---|
| Порушення axe (вузли) | 222: color-contrast 192, scrollable-region-focusable 14, select-name 8, target-size 8 | 0 |
| Текст менше 12 px | 4 220 | 0 |
| Сенсорні цілі менше 44 px | 2 136 | 0 |
| Горизонтальне переповнення | 0 | 0 |
| Помилки консолі | 0 | 0 |
| Концепт-арт на сторінках | PNG 1,8 МБ | AVIF 13,5 КБ (800 px) / 32,5 КБ (1600 px), WebP/JPEG fallback |

Основні причини «до»: світла тема не перевизначала частину токенів і мала жорстко задані кольори категорій (контраст); мітки й мета мали 7–11 px (3 232 з 4 220 випадків — 11 px); 1 476 з 2 136 малих цілей були нижчими за 24 px — порогу WCAG 2.5.8; прокручувані таблиці не фокусувалися; select на мобільному втрачав підпис.

## Як відтворити

З кореня репозиторію, сервер на 4318 (`node artifacts/after-hours-motion/serve.mjs`):

```powershell
node artifacts/after-hours/qa/check-tokens.mjs
node artifacts/after-hours/qa/run-qa.mjs --browsers=chromium
node artifacts/after-hours/qa/run-qa.mjs --browsers=firefox,webkit --quick
node artifacts/after-hours/qa/run-qa.mjs --browsers=chromium --quick --langs=en --motion=on
node artifacts/after-hours/qa/check-zoom.mjs
node artifacts/after-hours/qa/check-schema.mjs
node artifacts/after-hours/audit.mjs
```

Firefox і WebKit запускались через `QA_PLAYWRIGHT_CORE=<шлях до playwright-core 1.60.0>`, бо встановлені локально збірки (firefox-1522, webkit-2287) не збігаються з ревізіями вбудованого Playwright; звіт підписує збірку, якою реально виконано прогін.

## Межі перевірки

- **Реальні пристрої й screen readers не перевірялись.** WebKit і мобільні профілі Chromium — це рушії з емуляцією viewport/touch, не iOS Safari чи Android Chrome на пристрої. NVDA/JAWS/VoiceOver не запускались; доступність підтверджена axe, семантикою, фокусом і ручним переглядом.
- **CWV не виміряні.** Прототип рендериться на клієнті; LCP/INP/CLS міряти на production-like preview після імплементації.
- Замір кадрів — на одному комп’ютері; у headless Chromium без GPU на 1440×1000 p95 становить 33,2 мс (програмний рендеринг), на 390×844 — 16,8 мс.
- Автоматичні перевірки ловлять лише те, що шукають; повний ручний прохід клавіатурою по всіх станах у цій ітерації не повторювався.
- Контент демонстраційний; підписка нічого не надсилає; утиліти не є production engine.
