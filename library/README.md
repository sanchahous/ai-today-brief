# AI Today Brief — Library (Робочі матеріали дайджестів)

Єдиний локальний хаб для всіх робочих медіа-матеріалів відео- та аудіо-випусків AI Today Brief.

> ⚠️ **Важливе правило проєкту:** Усі бінарні робочі медіа-матеріали (відео, аудіо, ілюстрації, музика) зберігаються локально в цій папці та **НЕ комітяться в Git** (окрім коду інструментів у `library/tools/` та цієї документації).

---

## 📁 Структура директорії

```
library/
├── brand_info/                  # Офіційні логотипи, банери, бренд-графіка
│   ├── AI_today_brief_196_196.png
│   ├── AI_today_brief_banner_400_150.png
│   └── icon.svg
│
├── music/                       # Ліцензійна фонова музика для випусків
│   ├── energetic/               # Динамічні треки (Dyalla, Alex Jones тощо)
│   └── atmospheric/             # Атмосферні треки (Grey Room, Everet Almond тощо)
│
├── general_backgrounds/         # Універсальні фонові цикли, інтро та анімації
│   ├── intro-final.mp4          # Фінальний фірмовий відео-опенер
│   ├── mascots_and_entities/    # Концепти супутників/маскотів та AI сутностей
│   └── *.mp4 / *.jpg            # Фонове відео та рендер-заставки
│
├── tools/                       # Інструменти автоматизації (TTS, розпаковщики)
│   └── tts-generator/           # Автоматизація озвучки ElevenLabs
│
└── DD.MM.YYYY/                  # Матеріали конкретного випуску за датою (наприклад, 01.09.2026)
    ├── audio_scenes/            # Озвучені сцени (scene_01_cold_open.mp3 ... scene_18_outro.mp3)
    ├── video_scenes/            # Згенеровані B-roll кліпи (1.1 ... 3.5, Radar, Outro)
    └── images/                  # Редакційні 16:9 ілюстрації та інфографіка
```

---

## 🛠️ Робочий процес для нових випусків

1. **Озвучка:** Скористайтеся інструментом `library/tools/tts-generator/` для швидкої генерації та пакетного вивантаження 18 аудіо-сцен.
2. **Візуали:** Відео-сцени B-roll зберігайте у `library/DD.MM.YYYY/video_scenes/`.
3. **Музика та фони:** Обирайте потрібні треки та підкладки з `library/music/` та `library/general_backgrounds/`.
