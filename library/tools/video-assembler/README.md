# Video Assembler Tool (Автоматичний монтажер випусків)

Універсальний інструмент для автоматичного складання 18-сценних відео-дайджестів AI Today Brief.

## 🚀 Як використовувати

1. Переконайтеся, що в папці випуску `library/DD.MM.YYYY/`:
   - `audio_scenes/` містить 18 аудіо-файлів (`scene_01_cold_open.mp3` ... `scene_18_outro.mp3`);
   - `video_scenes/` містить відповідні B-roll кліпи.
2. Запустіть скрипт:
   ```bash
   node library/tools/video-assembler/assemble_digest.js
   ```
3. Скрипт автоматично:
   - піджене кожен кліп під 1920×1080 (30fps);
   - синхронізує хронометраж кожного відео-сегменту з тривалістю дикторської озвучки;
   - додасть мікро-паузи (0.35 с) на стиках сцен;
   - безшовно об'єднає всі 18 сегментів;
   - накладе фірмову фонову музику на 7.5% гучності з плавним Fade In (1.5 с) та Fade Out (2.5 с);
   - експортує готовий MP4 у `library/DD.MM.YYYY/atb_weekly_digest_DD_MM_YYYY.mp4`.
