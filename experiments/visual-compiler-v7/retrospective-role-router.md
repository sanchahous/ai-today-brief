# Visual Compiler v7 — role-router development simulation

This is a retrospective **development-set** simulation over the seven-story 2026-06-29 digest. It is not an unseen validation and must not be used as production evidence by itself.

## Routing rule

- `current_art_director`: `causal_mechanism`, `state_transition`, `policy_control`, `uncertainty_announcement`.
- `deterministic_compiler`: `architecture_transformation`, `quantitative_result`, `benchmark_comparison`, `capability_access`.

The rule uses only the source-audited explanatory role. It does not inspect the rendered image, per-story evaluator result, headline words or editorial rank.

## Simulated portfolio result

- Production pass: **5/7 (71%)**.
- Selected treatment was the blinded preference: **5/7 (71%)**.
- Average weighted score: **79.2**.
- Generated image calls: **4**, versus 7 for the all-current pipeline.
- Estimated image cost: **$0.060**, versus $0.105 for all-current.
- Measured serialized render time using the latest exact-current runs: approximately **411 seconds**, versus 1,140 seconds for all-current.
- Generated-text-free selected pixels: expected **7/7** on this development set because the router replaces the current quantitative card that contained generated text.

## Interpretation

The development evidence rejects both universal strategies:

1. all-generated current art direction is expressive but weak on exact numbers and bounded capability flows;
2. universal deterministic or independently planned metaphors are precise but often visually sterile or semantically indirect for causal stories.

A pre-render role router is currently the strongest architecture. The next decision must come from a completely fresh digest that was not used to formulate this rule.
