# Weekly Visual Compiler experiment

Branch: `experiment/visual-routing-backtest-20260812`

This experiment replaces the former universal `story -> metaphor prompt -> full image -> critic -> full regeneration` approach with a deterministic-first visual compiler for headline-paired weekly story cards.

No production database rows, current digest artifacts, or `main` code paths were changed during the experiment.

## Product contract

- Every image is displayed beside its headline.
- One image communicates one core claim.
- Up to three deterministic overlay groups are allowed.
- Style: cinematic explanatory editorial.
- Ranking weights:
  - instant meaning: 45%
  - visual beauty: 30%
  - brand consistency: 15%
  - originality: 10%
- Hard semantic gates run before weighted ranking.
- Accepted-image budget: at most `$0.10` and `60 seconds`.

## Architecture

```text
Approved story
  -> VisualClaim
  -> evidence/format router
  -> render-mode router
  -> isolated assets or deterministic cinematic template
  -> pixel-only semantic gate
  -> deterministic overlays and transitions
  -> headline-paired final gate
  -> targeted repair
```

### Visual formats

- `cinematic_single`
- `cinematic_sequence`
- `cinematic_split`
- `cinematic_cutaway`
- `cinematic_data_contrast`
- `cinematic_routing`

### Render modes

- `deterministic_vector`
- `generated_single`
- `generated_reference_sequence`
- `generated_action_pair`
- `generated_identity_action_pair`

Quantitative, architecture and task-routing stories use deterministic cinematic geometry. Temporal and human-behavior stories use generated assets with identity/continuity references. Text, arrows, numbers and layout are never generated by the image model.

## Backtest progression

| Iteration | Main approach | Pixel semantic pass | Final pass | Average score | Dominant failure |
|---|---|---:|---:|---:|---|
| v1 | all explanatory scenes generated | 1/7 | 1/7 | 59.3 | generated UI/text; absent outcomes |
| v2 | deterministic-first hybrid | 4/7 strict | 4/7 strict | 80.1 | identity gate miscalibrated; two outcomes weak |
| v3 | headline-paired gate + stronger energy consequence | 6/7 | 6/7 | 84.7 | Qwen route outcome not explicit |
| v4 | explicit completed outputs on both Qwen routes | 7/7 | 7/7 | 85.6 | none in this seven-story set |

The strict v2 identity gate required pixels alone to identify a named product even though the product headline is always visible. The calibrated gate keeps identity visibility diagnostic while hard-gating mechanism, outcome, cause-and-effect, contradiction, generated text and subject consistency.

## Cost model

The v2 experiment used five new image calls because the successful Muse sequence was reused. The production-equivalent policy for these seven stories would use eight image calls total:

- four deterministic stories: zero image calls;
- Muse sequence: three image calls;
- Tutor human split: three image calls;
- Codex non-human split: two image calls.

With the configured assumptions (`$0.015` per image call, `$0.01` per vision call, two vision calls per story), the estimated accepted-image cost is about `$0.265` for seven stories, or `$0.038` per story on average. Every story remains below `$0.10`.

## Targeted repair policy

- incorrect labels or thumbnail layout -> recompose overlays;
- generated text only -> edit/inpaint text region;
- missing physical mechanism or outcome -> regenerate only the failed asset;
- contradictory action or unsupported overlay -> replan the visual claim;
- exhausted semantic repair -> deterministic fallback.

A full-card regeneration is not the default repair action.

## Evidence and limitations

The result is strong evidence that the deterministic-first architecture fits the current digest better than a universal generated-metaphor pipeline. It is not yet proof of broad generalization:

- the seven stories were iteratively inspected during development;
- VisualClaims were curated for this experiment;
- the benchmark used one digest and one main vision judge;
- owner preference testing at production card size is still required;
- claim extraction and template selection need a separate unseen-story holdout.

## Safe production migration

1. Keep the current path unchanged.
2. Add `WEEKLY_VISUAL_COMPILER=shadow`.
3. Generate the compiler candidate beside the current artifact without making it current.
4. Show owner-blinded A/B cards at real feed size.
5. Log owner preference, reject reason, pixel gate, final gate, elapsed time and cost.
6. Promote only after an unseen multi-digest holdout and at least 70% owner preference over the current path.
